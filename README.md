1. Create your own Vercel account.

4. Deploy the project.
5. Open your new website URL.

Your deployed website will be completely separate from the demo website.

---

# 🔐 Customization Page Login

Royal Furniture Pro includes a private customization page protected by an admin password.

The password should be stored in a Vercel Environment Variable.

## Create the Admin Password

Inside your Vercel project:

1. Open your project.
2. Go to **Settings**.
3. Open **Environment Variables**.
4. Add a new variable.

### Name

`ADMIN_PASSWORD`

### Value

Choose your own private password.

Example:

`YourOwnPassword123!`

5. Save the variable.
6. Redeploy your Vercel project.

---

## ⚠️ Important Security Note

Do not use the password from the demo website.

Every customer should use their own password.

Each customer has their own Vercel project, so changing the `ADMIN_PASSWORD` in one project does **not** affect other customers.

For example:

Customer A:

`ADMIN_PASSWORD = MyPassword123`

Customer B:

`ADMIN_PASSWORD = AnotherPassword456`

These passwords are completely independent.

Never publish your admin password publicly.
